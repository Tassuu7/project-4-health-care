# AegisCare Clinical UI Design System

## Design Standards
A clean, accessible, high-contrast healthcare user interface engineered with modern HTML5, CSS3 CSS Variables, and modular JavaScript controllers.

### Portal Views:
1. **Executive Clinical Dashboard**: Real-time bed occupancy, ESI emergency queue, and active provider metrics.
2. **Triage Assessment Station**: Instant vital sign color-coded danger alerts and ESI calculator.
3. **Physician Consultation Console**: Interactive patient charts, past medical history, and 1-click prescription builder.
4. **Patient Self-Service Portal**: Secure view of health records, vitals graphs, and billing statements.
